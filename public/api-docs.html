Koleksi Endpoint
GET /v1/penggajian Tarik rekap gaji & kalkulasi kehadiran

Mengambil data penggajian karyawan per periode tanggal lengkap dengan rincian hari masuk, tarif harian, dan total gaji bersih.

Query Parameter Tipe Default Keterangan
start_date Date (YYYY-MM-DD) Awal bulan berjalan Tanggal mulai periode
end_date Date (YYYY-MM-DD) Akhir bulan berjalan Tanggal akhir periode
karyawan_id Integer - Filter spesifik per 1 karyawan
lokasi_id Integer - Filter per lokasi kandang
kandang_id Integer - Filter per kandang
bibit_id Integer - Filter per siklus bibit
Contoh cURL
curl -X GET "https://absplt.3putraperkasa.com/v1/penggajian?start_date=2026-10-01&end_date=2026-10-31" \ -H "X-Api-Key: f6db3e0c384f6685f1226476337878497c6daf3600435522237692aa224e020e" \ -H "Accept: application/json"
Format JSON Response (200 OK)
{ "success": true, "message": "Data penggajian berhasil diambil.", "meta": { "start_date": "2026-10-01", "end_date": "2026-10-31", "total_biaya": 44639166.67, "total_karyawan": 72 }, "data": [ { "karyawan_id": 1, "nama": "Mak Gik", "jabatan": "Bendo anak kandang", "gaji_pokok": "1800000.00", "total_hari_full": 22, "total_hari_half": 1, "total_gaji": 1350000, "start_date": "2026-10-02T00:00:00.000000Z", "end_date": "2026-10-26T00:00:00.000000Z" } ] }
